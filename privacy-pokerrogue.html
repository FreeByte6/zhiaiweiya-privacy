本政策适用于知艾薇亚提供的《口袋牌局大冒险》浏览器游戏及 Android 应用。请在使用前阅读本政策；您可以随时查看本政策并按下文方式联系我们。

当前 v1 为离线单机游戏，无账号、无登录、无内购，不收集任何个人信息。牌局进度、纪录与设置仅通过 localStorage 保存在您的设备本地，不上传、不出售，也不与第三方共享。

当前 v1 的游戏逻辑和模拟广告不发起网络请求。广告入口使用明确标注的离线模拟，未接入真实广告 SDK，不请求真实广告，也不采集设备或广告标识符。

当前 v1 的广告入口为明确标注的离线模拟，未接入真实广告或统计 SDK。未来如接入真实广告 SDK，我们会先更新政策，披露具体 SDK 及其数据处理规则，并提供相应选择。下文有关未来版本的说明不表示当前已经接入，也不构成您对未来数据处理的授权。

信息收集与使用

当前 v1 不要求您提供姓名、手机号、身份证号码、邮箱或任何账户资料；不读取通讯录、照片、通话记录、短信、位置、麦克风或摄像头，不采集设备唯一标识符、广告标识符、安装应用列表或用于跨应用跟踪的信息。

游戏不设置服务器账号、云存档、联网排行榜、聊天、社交分享、行为分析或远程崩溃上报服务。游戏逻辑和离线广告模拟不发起网络请求，不使用广告跟踪 Cookie 或网络追踪器，也不为游玩申请敏感权限。音效开关仅保存本机偏好，不访问麦克风。

您访问 TapTap 商店、下载游戏，或使用浏览器、操作系统本身的服务时，相应平台可能按照各自的政策处理信息；这些平台独立提供的服务不属于游戏本体的数据收集。

本地存储

游戏使用浏览器或 Android WebView 的 localStorage 保存以下牌局记录，全部保存在本机：

本地保存的内容与用途
本地内容用途
当前牌局及洗牌状态保存手牌、牌堆、关卡、星币和已购增益等进度，供本机继续游戏
个人纪录保存累计得分、最远通关关数与单手最高分，展示本机成绩
音效与手牌排序设置保留您选择的本机游戏偏好
模拟插屏的频控时间执行本机的展示间隔限制

这些记录不含账号身份资料，不发送给我们或第三方，也不用于跨设备识别。我们不提供云端同步或跨设备恢复。

记录通常保存至您清除站点／应用数据、卸载应用，或浏览器／系统清理本地存储；我们没有服务器副本可供恢复。操作系统或浏览器自行提供的备份、还原功能由其设置和政策管理。

管理与删除本地记录

您无需注册账户，因此无需办理账户注销。音效偏好可在游戏中切换；手牌排序可在牌桌上调整。

  • Web 版：通过浏览器的站点设置清除本游戏的站点数据。
  • Android 版：通过系统“设置 → 应用 → 口袋牌局大冒险 → 存储 → 清除数据”操作，具体名称以设备系统为准。

清除后，本机分数、牌局进度、设置及模拟广告频控记录将一并重置，通常无法恢复。仅退出游戏不会删除记录。

您可通过联系我们咨询个人信息处理情况，或提出查阅、复制、更正、删除、撤回同意等请求。当前游戏内记录只在您的设备上，我们无法远程读取或代为修改；我们会说明可用的本地操作方式。未来涉及 SDK 处理的信息，将按届时披露的具体渠道协助您行使权利。

第三方与广告

当前第三方广告、统计分析与跟踪 SDK 接入清单：无。当前 v1 的广告入口均为明确标注的离线模拟，不请求真实广告、不接入广告 SDK、不采集设备或广告标识符，也不向广告服务商发送数据。

当前 v1 没有向我们上传的个人信息，不向第三方共享、出售、转让或公开披露游戏内的个人信息，也不通过游戏进行个人信息的跨境传输。

未来如发生个人信息处理范围、合作方或传输安排的变化，我们会在实施前说明具体情况，并依法履行告知、取得同意等义务，不以本条概括授权代替具体披露。

未来接入真实广告 SDK 时的说明

未来可能选择 TapTap 广告（TapADN）或穿山甲广告（CSJ）作为广告服务提供方。当前二者均未接入，候选名称不代表当前发生数据共享。真实广告需要联网，但基础单机玩法仍可离线使用。

在实际接入的版本中，广告 SDK 在完成必要告知、取得相应同意并初始化后，可能在初始化、加载、展示及广告交互过程中采集以下信息：

  • 设备／广告标识符，例如 Android ID、OAID；具体是否处理及能否关闭取决于所选 SDK 版本与实际配置。
  • 设备型号、系统版本、应用包名和版本、网络类型与 IP 地址等运行信息。
  • 广告展示、点击、奖励验证、错误或性能信息，用于广告投放、效果统计、反作弊与服务稳定性。

设备标识符及上述相关信息可能构成个人信息，不能因为没有姓名或账号就视为“无个人信息收集”。这份可能范围不代表当前采集，也不能代替正式接入清单。

启用前我们会在游戏内隐私说明中列明实际 SDK 名称、版本、服务提供方及联系方式、处理目的、信息种类、采集方式与时机、保存期限、存储地点及权利行使方式，并提供第三方隐私政策链接。需要单独同意的事项将单独征求同意。

未来版本中的广告选择

  1. 同意前不初始化 SDK、不预加载广告、不读取或发送相关标识符。不同意不会影响牌局、八关闯关及无尽模式等基础玩法；涉及真实广告的续命及插屏不启用。
  2. 同意广告数据处理，不等于同意每次观看激励广告。失败续命入口仍须由您主动选择并提前说明奖励；取消观看不会扣除已有进度。
  3. 个性化广告默认关闭。若将来提供此功能，会另行说明并提供独立选择；关闭个性化不代表 SDK 完全不处理信息，非个性化广告也可能处理投放所需的信息。您可直接选择不启用真实广告。
  4. 接入 SDK 的版本会在“设置 → 隐私 → 广告与隐私”提供撤回选择。撤回后停止新的 SDK 调用和广告请求，清理可清理的缓存；不能立即停止相关处理的 SDK 将不启用。对第三方已经依法处理的数据，可通过披露的渠道或联系我们申请查阅、复制、删除等，我们会协助处理。
  5. 不因广告申请定位、通讯录、电话状态、相机、麦克风或安装应用列表等与核心玩法无关的可选权限；SDK 的实际最小采集范围会据实披露，无法满足保护要求时不启用该 SDK。

未成年人

游戏内容面向全年龄。扑克牌型仅作为离线计分规则，不涉及下注、现金输赢或可交易奖励；无暴力、血腥、内购或付费抽奖。建议未成年人在监护人指导下阅读本政策并合理安排游戏时间。

当前 v1 不收集未成年人个人信息。未来真实广告对已知未成年人及年龄未知的用户默认关闭，不进行行为画像或个性化广告推送，不以领奖、复活或连续签到诱导未成年人授权、观看广告或消费。不会为解锁广告要求提交身份证或生日。

如果未来确有必要处理不满十四周岁未成年人的个人信息，将先制定专门的处理规则，并在取得父母或其他监护人同意后依法处理；不能满足条件时不启用相关处理。监护人如有疑问或认为存在不当处理，可联系我们核查。

政策变更

我们按最小必要原则设计本地存储，不建立个人信息数据库，不上传存档。请使用您信任的设备并管理好浏览器／系统权限；本地记录不应存放身份证号、联系方式等敏感资料。

政策更新会标明生效日期。涉及新增 SDK、处理目的、信息种类、接收方或其他重要变化时，我们会在变更处理发生前显著告知，依法重新征求必要同意。您可拒绝新增的广告数据处理并继续使用基础离线玩法。
