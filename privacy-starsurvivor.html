本政策适用于知艾薇亚提供的《星际幸存者》Web／H5 游戏及 Android 游戏应用。请在使用前阅读本政策；您可以随时查看本政策并按下文方式联系我们。

当前 v1 为离线单机游戏，无账号、无登录、无内购，不要求身份资料，也不向外部上传游戏数据。航行存档、成绩与设置仅通过 localStorage 保存在您的设备本地，不上传、不出售，也不与第三方共享。

当前 v1 的游戏逻辑和模拟广告不发起网络请求。广告入口使用明确标注的离线模拟，未接入真实广告 SDK，不请求真实广告，也不采集设备或广告标识符。

当前版本没有接入真实广告 SDK。若未来版本拟接入真实广告或其他第三方服务，我们会在启用前更新本政策，说明实际服务方及其数据处理规则，并依法履行告知和取得同意等义务；本政策中的未来情形不表示当前已经接入。

信息收集与使用

当前 v1 不要求您提供姓名、手机号、身份证号码、邮箱或任何账户资料；不读取通讯录、照片、通话记录、短信、精确位置、麦克风或摄像头，不采集设备唯一标识符、广告标识符、安装应用列表或用于跨应用跟踪的信息。游戏会在本机生成并保存航行存档、成绩和设置，用于续玩及展示本机记录；这些数据不关联账号，也不会上传。

游戏不设置服务器账号、云存档、联网排行榜、聊天、社交分享、行为分析或远程崩溃上报服务。游戏逻辑和模拟广告不发起网络请求，不使用用于广告跟踪的 Cookie 或网络追踪器，也不为游玩申请上述敏感权限。音效与震动开关仅用于本机体验。

您访问 TapTap 商店、下载游戏，或使用浏览器、操作系统本身的服务时，相应平台可能按照各自的政策处理信息；这些平台独立提供的服务不属于游戏本体的数据收集。

本地存储

游戏使用浏览器或 Android WebView 的 localStorage 保存以下非联网游戏记录，全部保存在本机：

本地保存的内容与用途
本地内容用途
当前航行存档保存进行中的航行状态，供您在本机继续游戏
航行统计与最近记录记录航行次数、成功突围次数、击破数、最长时间、最高积分及最近航行结果
游戏设置保存合成音效、震屏与粒子效果及所选模式
离线广告模拟频控记录执行每局至多一次复活、结算插屏间隔及每局展示限制；只用于本机规则判断

这些记录不含账号身份资料，不发送给我们或第三方，也不用于跨设备识别。我们不提供云端同步或跨设备恢复。

记录通常保存至您清除站点／应用数据、卸载应用，或浏览器／系统清理本地存储；我们没有服务器副本可供恢复。操作系统或浏览器自行提供的备份、还原功能由其设置和政策管理。

管理与删除本地记录

您无需注册账户，因此无需办理账户注销。音效、震动等体验设置可在游戏设置中修改。

  • Web 版：通过浏览器的站点设置清除本游戏的站点数据。
  • Android 版：通过系统“设置 → 应用 → 星际幸存者 → 存储 → 清除数据”操作，具体名称以设备系统为准。

清除后，本机航行存档、成绩、设置及模拟广告频控记录将一并重置，通常无法恢复。仅退出游戏不会删除记录。

您可通过联系我们咨询个人信息处理情况，或提出查阅、复制、更正、删除、撤回同意等请求。当前游戏内记录只在您的设备上，我们无法远程读取或代为修改；我们会说明可用的本地操作方式。未来涉及 SDK 处理的信息，将按届时披露的具体渠道协助您行使权利。

第三方与广告

当前第三方广告、统计分析与跟踪 SDK 接入清单：无。当前 v1 的广告入口均为明确标注的离线模拟，不请求真实广告、不接入广告 SDK、不采集设备或广告标识符，也不向广告服务商发送数据。

当前 v1 没有向我们上传的个人信息，不向第三方共享、出售、转让或公开披露游戏内的个人信息，也不通过游戏进行个人信息的跨境传输。

未来如发生个人信息处理范围、合作方或传输安排的变化，我们会在实施前说明具体情况，并依法履行告知、取得同意等义务，不以本条概括授权代替具体披露。

未来接入真实广告或第三方 SDK 时

当前版本未接入任何真实广告 SDK。如未来版本拟接入，基础单机玩法仍将保持可离线使用；启用前我们会在政策和游戏内说明中列出实际服务提供方、SDK 名称与版本、联系方式、处理目的、信息种类、采集方式与时机、保存期限、存储地点、权利行使方式及第三方隐私政策链接。需要单独同意的事项将单独征求同意。

具体 SDK 及配置确定后，届时可能处理的信息类别以实际接入清单为准，可能包括设备或广告标识符、设备与应用运行信息、网络信息，以及广告展示、点击、奖励验证、错误或性能信息。上述仅为可能类别，不代表当前采集，也不能替代正式披露。我们不会仅凭这段说明开始处理相关信息。

未来版本中的广告选择

  1. 如未来真实广告处理需要您的同意，我们会在启用前说明实际服务方、数据处理方式和选择渠道；不同意该处理不会影响基础离线玩法，相关真实广告功能将不启用。
  2. 激励广告仍由您主动选择。届时会在入口说明奖励，取消观看不扣除已有进度；未完成广告不发放奖励。当前 v1 的复活与结算广告均为离线模拟。
  3. 如未来 SDK 版本提供撤回同意或关闭广告处理的设置，我们会在更新的政策和游戏内说明中列出操作方式；不能满足必要告知、选择或数据保护要求的服务不会启用。
  4. 不因广告申请与核心玩法无关的权限；未来 SDK 的实际处理范围会在接入前据实披露。

未成年人

游戏内容面向全年龄，以飞船对抗卡通星际虫群为主题，包含自动射击与击破表现，无血腥画面；不含赌博、内购或付费抽奖。建议未成年人在监护人指导下阅读本政策并合理安排游戏时间。

当前 v1 不要求未成年人提供身份资料，也不向外部传输其本机航行记录。未来如接入真实广告，将按届时适用规则处理未成年人相关信息，不进行行为画像或个性化广告推送，不以领奖或复活诱导未成年人授权、观看广告或消费。不会为解锁广告要求提交身份证或生日。

如果未来确有必要处理不满十四周岁未成年人的个人信息，将先制定专门的处理规则，并在取得父母或其他监护人同意后依法处理；不能满足条件时不启用相关处理。监护人如有疑问或认为存在不当处理，可联系我们核查。

政策变更

我们按最小必要原则设计本地存储，不建立个人信息数据库，不上传存档。请使用您信任的设备并管理好浏览器／系统权限；本地记录不应存放身份证号、联系方式等敏感资料。

政策更新会标明生效日期。涉及新增 SDK、处理目的、信息种类、接收方或其他重要变化时，我们会在变更处理发生前显著告知，依法重新征求必要同意。您可拒绝新增的广告数据处理并继续使用基础离线玩法。
